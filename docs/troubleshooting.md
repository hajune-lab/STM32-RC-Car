# 트러블 슈팅

실험 중 겪은 문제와 현재 코드에 반영한 대응을 정리하였다. 대응 로직을 추가한 사실이 모든 트랙에서의 해결을 의미하지는 않는다. 정량적인 완주율·충돌률 자료는 아직 포함하지 않았다.

| 문제 | 분석·확인 | 반영한 대응 | 남은 확인 |
| --- | --- | --- | --- |
| ENA·ENB 점퍼 제거 후 수동 구동 불가 | Enable HIGH를 PWM 출력이 대신해야 함 | TIM4 CH3/CH4 연결과 PWM 시작·비교값 적용 | 실제 배선·PWM 파형 |
| 좌우·전후 방향 혼동 | 차체 앞 방향·배선·논리 좌우 대응 확인 | 좌우 교환·극성 상수와 물리 채널 시험 분리 | 채널별 실제 회전 방향 |
| 비스듬한 벽에서 미검출·이상값 | 초음파 반사·응답 상태가 판단에 영향 | 순차 측정, 정숙 시간, 필터·상태·유효기간 분리 | 재질·각도별 반복 측정 |
| 통로 폭에 따라 한쪽 벽에 붙음 | 절대 거리 차이만으로 폭 변화 대응이 어려움 | 거리 비율 기반 중앙 PD와 별도 근접 회피 | 센서 각도·모터 편차 |
| 코너 과회전·역방향 진입 | 회전 중 얻은 측면값과 방향 판단 영향 | 정면 개방 시 회전 해제, 새 측면값 대기, 코너 방향 기억 | 마지막 코너·유턴 반복 주행 |
| 장애물 앞에서 회전 정체 | 회전 공간과 방식의 영향 | 곡선·한쪽 정지·역회전 선택, 짧은 후진·재측정 | 차체 폭·회전 반경 |
| 빈 구간에서도 출력이 낮음 | 거리·측정 신선도·보정에 따른 출력 제한 | 서행·순항·최고 출력 분리, 조건 만족 시 100% 허용 | 배터리·L298N 손실·실제 속도 |
| 로그 송신이 주행을 지연시킬 가능성 | 긴 동기 송신은 루프를 지연시킬 수 있음 | 버퍼·TXE 폴링으로 비차단 송신 | 실제 루프 주기·로그 누락 |

## 다음 검증

1. 전체 CubeIDE 프로젝트와 .ioc를 추가하고 실제 빌드를 기록한다.
2. 동일 트랙·배터리 조건에서 완주율, 충돌 횟수, 소요 시간을 반복 측정한다.
3. 센서·상태·출력·판단 이유 로그를 주행 영상과 비교한다.
4. 수동 통신 단절 시 자동 정지 기능 추가를 검토한다.
