# 주행 구조와 주요 설정

App_Init()은 보드 → 디버그 UART → 모터 → 초음파를 초기화하고 정지 상태로 시작한다. App_Task()는 센서 → 버튼 → 통신 → 주행 판단 → 모터 → 로그·LED 순서로 처리한다. Trig 생성 중에는 센서 처리를 우선한다.

RTOS 없이 현재 시각과 이전 실행 시각을 비교해 작업한다. 주행 판단과 모터 갱신의 기본 간격은 10 ms이다.

## 주행 상태

| 상태 | 역할 |
| --- | --- |
| STOP | 정지·명령 대기 |
| ACQUIRE | 정지 후 재측정·유효값 확보 |
| DRIVE | 전진·중앙 보정·출력 조절 |
| CORNER | 회전 방향·방식 선택과 출구 확인 |
| BACK | 짧은 후진 후 ACQUIRE 복귀 |
| MANUAL_DRIVE | 블루투스 방향 명령 유지 |
| TEST | 정지 상태에서 요청한 모터 시험 |

수동·자율 모드는 주행 상태와 별도로 관리한다. 버튼 디바운스는 30 ms이다. 코너 방향은 짧은 후진 중에도 기억하며, 전진과 정면 개방 확인 조건을 충족한 뒤 해제한다. 회전 후 새 측면값으로 중앙 보정을 재개한다.

## 설정값

REBUILD_16_BT의 기본값이다. PWM은 출력 명령 비율이며 실제 속도 측정값이 아니다.

| 항목 | 값 |
| --- | --- |
| 최소 구동 / 서행 / 순항 / 최고 PWM | 65 / 70 / 90 / 100% |
| 수동 전후진 / 회전 PWM | 100 / 85% |
| 일반 코너 진입 | 정면 24 cm 이하, 근접 확인 2회 |
| 코너 개방 거리 기준 | 정면 27 cm 초과, 연속 확인 조건 적용 |
| 정면 긴급 근접 기준 | 10 cm |
| 최고 출력 조건 중 거리 기준 | 정면 65 cm 이상, 좌우 각각 12 cm 이상 |
| 중앙 PD | Kp=9.0, Kd=0.8, 기본 보정 ±4 PWM |
| 가속 / 감속 | 10 ms마다 최대 +5 / −6 포인트 |
| 방향 전환 대기 | 40 ms |
| 후진 실제 적용 시간 기준 | 100 ms |
| Trig HIGH | 12 μs |
| 트리거 시작 간격 | 최소 40 ms |
| 같은 센서 간격 | 최소 65 ms |
| 측정 종료 후 정숙 시간 | 최소 12 ms |
| Echo 타임아웃 | 30 ms |
| 로그 주기 | 500 ms, 센서가 유휴일 때 송신 준비 |

센서 스케줄러는 코너·재측정 시 정면을 우선하고 좌우를 번갈아 선택한다. 과거 실험의 10/65/75 ms와 달리 이 버전은 위 설정을 사용한다.

## USART2 디버깅

로그는 모드·상태, F/L/R 거리·상태 코드, 출력, 회전 방향·기억, 판단 이유를 담는다. 로그의 cmd 필드는 Motor_GetActual()로 얻은 적용 PWM이다.

| 명령 | 동작 |
| --- | --- |
| S | 정지·수동 복귀 |
| G | 정지 상태에서 자율 시작 |
| M / N | 정지 상태에서 물리 ENA / ENB 시험 |
| L / R | 정지 상태에서 한쪽 구동 시험 |

시험은 기본 72%로 500 ms 수행한다. USART2 시험 명령과 USART1 블루투스 방향 명령은 용도가 다르다.
