# STM32 RC Car

**블루투스 수동 조작과 초음파 센서 기반 자율주행을 구현한 4륜 RC카**

STM32 NUCLEO-F411RE에 HC-06, 초음파 센서 3개, L298N을 연결하였다. 스마트폰 명령으로 차량을 조작하고 파란 버튼으로 자율주행 모드를 전환한다. 좌우 바퀴의 방향과 PWM 출력을 다르게 주어 조향한다.

> 이 저장소는 RC_Modular.zip의 응용 소스 16개를 담고 있다. 전체 CubeIDE 프로젝트가 아니며 `.ioc`, HAL/CMSIS, 시작 코드, 링커 스크립트, 주변장치 생성 파일은 포함하지 않는다. 기존에 동작하던 CubeIDE 프로젝트에 적용해야 한다.

## 주요 기능

| 기능 | 구현 내용 |
| --- | --- |
| 블루투스 수동 조작 | USART1으로 F / B / L / R / S 명령 수신 |
| 모드 전환 | PC13 파란 버튼으로 수동·자율 전환, 부팅 시 수동 정지 |
| 거리 측정 | 정면·좌·우 순차 측정, 필터와 측정 상태·유효기간 관리 |
| 자율주행 | 전진을 기본으로 중앙 보정, 장애물 접근 시 코너 판단 |
| 주행 복구 | 공간과 회전 진행 상태에 따라 짧은 후진 후 재측정 |
| 모터 제어 | TIM4 PWM, 가감속, 정·역전 전환 대기시간 |
| 디버깅 | USART2로 거리·주행 상태·PWM·판단 이유 출력 |

## 개발 환경

| 항목 | 구성 |
| --- | --- |
| 보드 | NUCLEO-F411RE / STM32F411RE |
| 도구·언어 | STM32CubeIDE, STM32CubeMX, STM32 HAL, C |

| 차체·드라이버 | 4WD 차체, L298N, 좌우 각각 앞뒤 모터를 한 그룹으로 연결 |

## 코드 구조

main.c는 초기화와 반복 실행만 담당하고 기능별 모듈을 호출한다.

```c
int main(void)
{
    App_Init();
    while (1)
    {
        App_Task();
    }
}
```

| 소스 | 역할 |
| --- | --- |
| [main.c](Core/Src/main.c) | 응용 초기화와 반복 실행 |
| [app.c](Core/Src/app.c) | 모드 전환, 상태 머신, 중앙 보정, 코너·복구 판단 |
| [bt.c](Core/Src/bt.c) | 블루투스 수신과 명령 해석 |
| [ultrasonic.c](Core/Src/ultrasonic.c) | Trig/Echo, 측정 순서, 필터·상태 관리 |
| [motor.c](Core/Src/motor.c) | 방향·PWM 출력, 가감속, 방향 전환 대기 |
| [debug_uart.c](Core/Src/debug_uart.c) | 디버그 명령과 비차단 로그 송신 |
| [board.c](Core/Src/board.c) | 클럭·주변장치·GPIO 초기화 |
| [rc_config.h](Core/Inc/rc_config.h) | 거리·출력·시간·게인 설정 |

## 제어 방식

양쪽 벽이 보일 때는 `e = (L - R) / max(L + R, 1)`로 거리 불균형을 계산하고 PD 보정을 적용한다. 한쪽 벽만 보이면 해당 벽과의 기준 거리를 사용한다.

정면 장애물에 접근하면 측면 거리와 거리 증가 이력을 이용해 회전 방향을 판단한다. 공간에 따라 전진 곡선 회전, 한쪽 바퀴 정지 회전, 좌우 역방향 회전을 선택한다. 정면이 열리면 회전을 풀고 새 측면값으로 전진 보정을 재개한다.

미검출을 무조건 빈 공간으로 처리하지 않는다. Echo 오류·고정·측정값 노후화와 NO_TARGET을 구분해 재측정 또는 서행 경로로 처리한다.

## 실행 방법

1. 기존 NUCLEO-F411RE CubeIDE 프로젝트를 백업한다.
2. 이 저장소의 Core/Src 7개 .c와 Core/Inc 9개 .h를 같은 경로에 복사한다.
3. 기존 main.h, tim.c/.h, usart.c/.h, HAL/CMSIS, 인터럽트·시작 코드, .ioc를 유지한다.
4. [핀 연결과 설정](docs/hardware.md)을 기존 설정과 대조한다.
5. Refresh → Clean → Build Project 후 보드에 다운로드한다.
6. 수동 정지 상태에서 통신을 확인하고 파란 버튼으로 모드를 전환한다.

기존 main.c 백업은 프로젝트 밖에 보관한다. Core/Src에 main_old.c 등을 함께 넣으면 main, SystemClock_Config, Error_Handler가 중복 정의될 수 있다.

| USART1 명령 | 동작 |
| --- | --- |
| F | 전진 |
| B | 후진 |
| L | 좌회전 |
| R | 우회전 |
| S | 정지·수동 모드 복귀 |

소문자도 허용한다. 방향 명령은 수동 모드에서, S는 자율 모드에서도 처리한다. 앱은 버튼을 놓을 때 S를 보내도록 설정해야 한다. 이 버전에는 명령 미수신 시간에 따른 자동 정지가 없다.

## 자료와 검증 범위

기존 모듈화 C 소스와 헤더는 변경하지 않았다. 이번 업로드에서는 원본과의 무결성, 문서 링크·구성, 원격 저장 결과를 확인한다. STM32CubeIDE 실제 빌드와 보드 주행은 이번 업로드 과정에서 실행하지 않았다.

과거 모의 검사 기록은 원본 적용 안내에 보존하였으며 해당 검사 도구는 이 저장소에 포함하지 않았다. 완전한 재현을 위해 기존 CubeIDE 프로젝트와 실제 하드웨어 검증 기록을 추가해야 한다.
